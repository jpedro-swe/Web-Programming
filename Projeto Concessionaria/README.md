# Projeto Concessionaria

Este diretório representa a versão atual do sistema da concessionária, com o nome atualizado para refletir melhor o objetivo do projeto.

## Observação

O projeto principal continua armazenado na estrutura anterior por compatibilidade do desenvolvimento, mas a referência oficial agora passa a ser:

- `Projeto Concessionaria`

## Objetivo

Gerenciar cadastros e operações de uma concessionária, incluindo:

- clientes
- funcionários
- marcas
- modelos
- vendas
