## Visão Geral

Este projeto foi desenvolvido para gerenciar as operações básicas de uma concessionária, organizando cadastros e consultas de informações essenciais ao negócio.

O sistema permite controlar:

- clientes
- funcionários
- marcas
- modelos
- vendas

## Funcionalidades

- cadastro de clientes
- cadastro de funcionários
- cadastro de marcas
- cadastro de modelos
- cadastro de vendas
- listagem de registros
- edição e atualização de dados
- navegação por menu com interface Bootstrap

## Como Executar

### Pré-requisitos

- servidor local (XAMPP, WAMP ou outro)
- PHP instalado
- MySQL configurado

### Passos

1. Abra a pasta `projeto jp` no servidor local.
2. Inicie o ambiente de desenvolvimento.
3. Acesse o arquivo `index.php` pelo navegador.

Exemplo:

```bash
php -S localhost:8000
```

Depois acesse:

```text
http://localhost:8000/
```
