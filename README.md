## Visão Geral

Este repositório foi criado para armazenar exercícios, mini projetos e práticas de desenvolvimento web, com foco em HTML, CSS e JavaScript. A ideia é organizar os aprendizados de forma clara e evolutiva, desde conceitos básicos até projetos mais completos.

## Estrutura do Repositório

```text
Web-Programming/
├── README.md
├── Olá Mundo/
│   └── index.html
└── projeto jp/
```

## Projetos e Conteúdos

### 1. Olá Mundo
Diretório responsável por um primeiro exercício de HTML básico, com a criação de uma página simples.

Arquivo principal:
- `Olá Mundo/index.html`

### 2. Projeto JP
Estrutura de projeto em desenvolvimento para praticar organização de arquivos e criação de páginas web.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como Executar

### Método 1: Abrir diretamente no navegador
1. Acesse a pasta do projeto.
2. Abra o arquivo `index.html` no navegador.

### Método 2: Usar um servidor local
Se quiser testar em ambiente mais próximo do real:

```bash
python -m http.server 8000
```

Depois abra no navegador:

```text
http://localhost:8000
```

## Objetivos do Projeto

- aprender os fundamentos do desenvolvimento web
- praticar estruturação de páginas HTML
- explorar estilos com CSS
- iniciar a lógica com JavaScript
- manter um repositório organizado e versionado
